# Как пересобрать графики зарплат

Полная цепочка: **CSV → salary_analysis.py → проверки → 17 графиков PNG/SVG и 5 сводных CSV → README и галерея**.

## На компьютере

В терминале откройте папку репозитория. Рекомендуется Python 3.12 и отдельное виртуальное окружение.

```bash
python -m pip install -r requirements-rebuild.txt
python build_portfolio.py
```

Для своего файла:

```bash
python build_portfolio.py /path/to/vacancies.csv
```

Поддерживаются CSV и CSV.GZ со схемой из [DATA.md](DATA.md). По умолчанию используется `vacancies.csv.gz`. Архив содержит все 100 000 строк исходной выгрузки; сжатие не меняет данные.

## На GitHub

Измените `salary_analysis.py` или файл `vacancies.csv.gz` и сохраните изменения в main. Автоматическая сборка запустится во вкладке **Actions → Rebuild charts**. Для повторного запуска без изменения файлов: **Run workflow → main → Run workflow**.

Для замены встроенного источника сожмите свой CSV командой ниже из корня репозитория. После сохранения нового архива в main Actions пересоберёт графики.

```bash
python -c "import gzip,pathlib; p=pathlib.Path('/path/to/vacancies.csv'); pathlib.Path('vacancies.csv.gz').write_bytes(gzip.compress(p.read_bytes(),mtime=0))"
```

## Проверки и результаты

Уникальность идентификаторов, обязательные поля, положительность зарплат, категории опыта, согласованность численностей, порядок квартилей и наличие всех 34 файлов графиков. В расчётах сохраняются пропуски и обратные вилки по описанной методике. Заметки на графиках и общая медиана для городов вычисляются из текущих данных.

После успешной проверки обновляется только `generated/`. Отчёт: [REPORT.md](generated/REPORT.md); версии библиотек, контрольные суммы входа, кода и результатов: [build-manifest.json](generated/build-manifest.json). Если расчёт падает, автоматическая сборка не записывает неполный результат в main.

README и CHARTS.md показывают пересчитанные графики из `generated/`. При смене набора данных пересматриваю текстовые выводы отдельно от автоматического расчёта графиков.

Автоматическая сборка фиксирует версии основных библиотек; результаты проверяются по данным и контрольным суммам. Между разными ОС внешний вид шрифтов и PNG может немного отличаться. При отсутствии изменений новый коммит не создаётся. Архив результатов последней сборки доступен в Actions 14 дней.
