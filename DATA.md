# Исходные данные и расчёт показателя

Учебный датасет `vacancies.csv`: 100 000 строк и шесть полей. Первичный источник, период выгрузки, валюта исходной выгрузки и репрезентативность не подтверждены. В исходном задании зарплаты трактовались как рубли; графики сохраняют эту интерпретацию. Это не оценка текущего рынка труда.

| Поле | Назначение |
|---|---|
| vacancy_id | Уникальный идентификатор вакансии |
| salary_from | Нижняя граница зарплаты или пустое значение |
| salary_to | Верхняя граница зарплаты или пустое значение |
| experience | Одна из четырёх категорий требуемого опыта |
| city | Город |
| employment_type | Тип занятости |

При наличии двух границ использовано `(salary_from + salary_to) / 2`. При одной — указанная граница. При отсутствии обеих строка исключена только из зарплатной выборки и сохранена в анализе пропусков.

Контрольная сумма SHA-256 исходного файла:

```
1de539f98acd186b911833fc92b7ba68e7cfff59728ccdd234c5939165382463
```

Исходные строки не опубликованы. Для построения всех графиков нужен локальный файл с этой схемой. В репозитории доступны сводные CSV, исходный код графиков, PNG и SVG.

Сравнение городов в `city-medians.csv` относится к опыту **1–3 года**. В матрице `salary-cities-matrix.png` показаны все четыре категории; численности ячеек сохранены в `city-counts.csv`.

Линейная гистограмма показывает зарплаты до 1 млн ₽; наблюдения выше границы сохранены в остальных графиках и расчётах. Доли на гистограмме рассчитаны от всех вакансий группы с указанной зарплатой. Boxplot скрывает маркеры выбросов, но не исключает их из данных. Violin plot и профили плотности сглажены в логарифмах; их ширина не равна численности группы.
