### Подготовка данных

В исходном файле 100 000 строк. Зарплата указана у **74 410** вакансий; у **25 590** отсутствуют обе границы. Если указаны две границы, я беру их среднее; если одна — использую её. Обнаружено 987 обратных вилок. В основном расчёте я учитываю их, а исключение рассматриваю отдельно как проверку чувствительности.

```python
df["salary"] = df[["salary_from", "salary_to"]].mean(axis=1)
valid = df.dropna(subset=["salary"])
summary = valid.groupby("experience")["salary"].agg(
    count="count", mean="mean", median="median"
)
```

### Границы выводов

Датасет не позволяет оценить текущий рынок труда без проверки происхождения, периода и состава вакансий. Различия медиан не доказывают влияние только опыта. Для статистического сравнения групп 3–6 и 1–3 года я применил U-критерий Манна — Уитни и ранговый размер эффекта: около 0,097. Малое p-значение при большой выборке я не приравниваю к большому практическому эффекту. Численные результаты относятся к выборке и допущению независимости вакансий.
